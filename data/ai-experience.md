# AI Experience

Ryan has worked with AI in the following ways:

- Sponsored the introduction of AI-assisted code review and code
  generation tools within engineering teams at DigiCert, evaluating
  their impact on developer productivity and code quality.
- Explored using large language models for internal support tooling,
  including a proof-of-concept for answering internal documentation
  questions using retrieval-augmented generation (RAG) techniques.
- Built this very application (ResumAI) as a hands-on example of
  integrating an LLM with a curated, factual knowledge base to avoid
  hallucinated answers.
- Has a strong point of view on responsible AI usage in engineering
  organizations: using AI to augment rather than replace engineering
  judgment, and being explicit about what a model does and does not
  know.
